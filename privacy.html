개인정보처리방침

시행일: 2026년 10월 12일

이 방침은 유튜브 채널 "이슈브리핑"의 운영자가 직접 쓰는 영상 업로드 도구 (Google OAuth 앱 이름: "n8n YouTube Upload", 이하 "도구")에 적용됩니다.

1. 이용하는 정보

도구는 Google 계정의 youtube.upload 권한 하나만 요청합니다. 이 권한으로 운영자 본인의 유튜브 채널에 영상을 업로드하는 것 외에는 아무것도 하지 않습니다. 다른 사용자의 계정, 시청 기록, 연락처 등 어떤 개인정보도 읽거나 수집하지 않습니다.

2. 보관

Google 로그인 후 발급되는 인증 토큰은 운영자의 컴퓨터에만 저장되며, 외부 서버로 전송하거나 다른 곳에 보관하지 않습니다.

3. 제3자 제공

Google 사용자 데이터를 판매하거나 제3자에게 제공·공유하지 않습니다.

4. Google API 서비스 사용자 데이터 정책 준수

도구가 Google API로부터 받은 정보를 사용하고 다른 앱으로 전송하는 방식은 제한된 사용(Limited Use) 요구사항을 포함한 Google API 서비스 사용자 데이터 정책을 따릅니다.

5. 권한 철회

언제든지 Google 계정 권한 페이지에서 도구의 접근 권한을 철회할 수 있습니다.
